# Как проходить практикум

## Правила

1. **Иди по порядку.** Каждая лаба опирается на предыдущую.
2. **Сначала сделай, потом подглядывай.** В каждой лабе есть блок
   «Эталон» под спойлером. Открывай его после своей попытки или если
   застрял дольше чем на пять минут — но не раньше.
3. **Проверяй результат командой, а не глазами.** В каждой лабе есть раздел
   «Проверка» с конкретной командой и ожидаемым выводом.
4. **Коммить после каждой лабы.** В конце будет полезно посмотреть историю.

## Известная особенность приложения

Детонатор №6 (ошибка при рендере React) оставляет **пустой экран** вместо
экрана ошибки. Это не твоя ошибка и не поломка практикума — это баг
Excalidraw: фолбэк `TopErrorBoundary` использует `Trans`/`t()`, которым нужен
jotai-`Provider`, а тот отрисован внутри самой границы и при фолбэке уже не
существует. В консоли это видно как `Missing Provider from createIsolation`.
Лечится перезагрузкой страницы. В лабе 01 ты это обойдёшь.

## Требования

- Node 18+ (проверено на 26.7.0), yarn 1.x
- `jq` — с лабы 02b: `mise use -g jq`
- Аккаунт на [sentry.io](https://sentry.io) — хватит бесплатного
- Аккаунт GitHub с настроенным `gh` — понадобится в лабе 07
- **Блокировщик рекламы, выключенный на страницах твоего приложения** —
  `localhost:5001`, `localhost:5002`, а в лабе 07 и на `<логин>.github.io`.
  Не на `sentry.io`: туда ты ходишь читать Issues, там он не мешает.

  Блокировщики держат домены Sentry в списках трекеров и отменяют запрос к
  ingest-эндпоинту прямо в браузере. SDK об этом не узнаёт и молчит, поэтому
  симптом — «в Issues пусто, в консоли тишина» — неотличим от опечатки в DSN.
  Это причина примерно половины «у меня ничего не работает».

  Проверяется за пять секунд: DevTools → Network → фильтр `ingest`, нажать
  детонатор. Запроса нет или он `(blocked:client)` — блокировщик. Ушёл с
  ответом `200` — долетело. `403` — неверный DSN или проект.

  Учти, что Brave блокирует это своими щитами, а Firefox — строгой защитой от
  отслеживания. Отсутствие uBlock ещё ничего не гарантирует.
